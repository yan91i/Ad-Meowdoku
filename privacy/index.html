Privacy policy

This page describes the privacy posture for Meowdoku. The browser page is designed to be playable without accounts, payments, comments, or required personal information.

Data collection

The site does not create user accounts, collect payment details, or require personal information to play the browser game. If you email the contact address, your message is used only to respond to that request.

Analytics

Analytics provider: none. This build is configured with analytics disabled, so no analytics script is loaded and the site makes no third-party requests.

Local storage and service worker

The PWA shell may cache static files and the game shell on the player's device so the site can reopen quickly. The embedded game may also store local progress or preferences in the player's browser.
